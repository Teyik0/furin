# Security policy

## Supported versions

Security reports are investigated for the latest published `@teyik0/furin` release and the current `main` branch. Older prereleases are not maintained separately; upgrade to the latest release when a fix is published.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/teyik0/furin/security/advisories/new). Include the affected version, a minimal reproduction, the expected and observed behavior, and the potential impact. Do not include secrets or personal data in the report.

If the private reporting form is unavailable, [open an issue requesting a private contact](https://github.com/teyik0/furin/issues/new) without publishing exploit details. Please do not disclose the vulnerability publicly before maintainers have had an opportunity to investigate and coordinate a fix.

The maintainers will acknowledge reports, assess their impact, and coordinate disclosure and a security advisory when appropriate. This policy does not claim that a suspected issue is an exploitable vulnerability before it is verified.

## Known advisories

`bun audit` on this repository reports [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) (CVE-2026-93687, high): stack-exhaustion denial of service in `braces` `<=3.0.3` through deeply nested patterns. No patched `braces` release exists; 3.0.3 is the latest. The only path to it is the `ultracite` lint tooling (`ultracite > fast-glob > micromatch > braces`, also through `find-workspaces`), a development dependency that expands glob patterns from local configuration. `@teyik0/furin` does not depend on `braces`; projects generated by `create-furin` only get it through their own `ultracite` development dependency. The advisory is left visible rather than ignored, and the dependency will be updated once a fixed release is published.
