# Deferred Data

Furin supports deferred streaming from `loader()`: synchronous values enter the initial HTML shell while promise-valued fields resolve in later chunks.

## Using `defer()`

`defer()` and `<Await>` are client-safe exports. The route builder itself comes from the server entry.

```tsx
// src/pages/dashboard/index.tsx
import { defineRoute } from "@teyik0/furin"
import { Await, defer } from "@teyik0/furin/client"
import { Suspense } from "react"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssr" })
  .loader(async () => {
    const title = "Dashboard"
    const stats = fetchAnalytics()
    return defer({ stats, title })
  })
  .page(({ data: { stats, title } }) => (
    <div>
      <h1>{title}</h1>
      <Suspense fallback={<Spinner />}>
        <Await resolve={stats}>
          {(value) => <AnalyticsChart data={value} />}
        </Await>
      </Suspense>
    </div>
  ))
```

`<Await>` uses React's `use()` internally. It must be inside a `<Suspense>` boundary.

## Error Handling

Provide `errorElement` for a local fallback. `useAsyncError()` reads the rejection inside that fallback.

```tsx
import { Await, useAsyncError } from "@teyik0/furin/client"

function ErrorCard() {
  const error = useAsyncError()
  return <p>Failed to load stats: {String(error)}</p>
}

<Await errorElement={<ErrorCard />} resolve={stats}>
  {(value) => <AnalyticsChart data={value} />}
</Await>
```

Without `errorElement`, the rejection propagates to the nearest React error boundary. `useAsyncValue<T>()` is available when a child component is more convenient than the render-prop form.

## Layout Loaders

The same contract applies to layouts.

```tsx
import { defineRootRoute, HeadContent, Scripts } from "@teyik0/furin"
import { Await, defer } from "@teyik0/furin/client"
import { Suspense } from "react"

export const route = defineRootRoute()
  .config({ mode: "ssr" })
  .loader(() =>
    defer({
      user: "alice",
      widgets: fetchSidebarWidgets(),
    })
  )
  .layout(({ children, data: { user, widgets } }) => (
    <html lang="en">
      <head>
        <HeadContent />
      </head>
      <body>
        <nav>Hello {user}</nav>
        <Suspense fallback={<WidgetSkeleton />}>
          <Await resolve={widgets}>{(value) => <WidgetList widgets={value} />}</Await>
        </Suspense>
        <main>{children}</main>
        <Scripts />
      </body>
    </html>
  ))
```

Layout and page promises share the same transport. If both loaders return the same key, the page value wins, matching the synchronous merge order.

## Restrictions

- Always wrap `<Await>` in `<Suspense>`.
- SPA navigation reconstructs the same promise-valued `data` contract through `/_furin/data`.
- `defer()` is SSR-only. SSG and ISR routes must await public loader data or use `requestLoader()` for per-request sections below Suspense.

| Approach | When to use |
| --- | --- |
| Normal loader | all public data is needed before paint |
| `defer()` | some SSR data can stream after the shell |
| `requestLoader()` | data is request-specific and must stay out of a cached shell |
