# Data Loading

Furin loaders run on the server before rendering. A route is one `defineRoute()` chain whose terminal is `page()` or `layout()`.

## Page Loader

Use `loader()` for public data that is serialized into the rendered page.

```tsx
// src/pages/dashboard/index.tsx
import { defineRoute } from "@teyik0/furin"
import { route as parentRoute } from "../root"

export const route = defineRoute()
  .config({ layout: parentRoute, mode: "ssr" })
  .loader(async () => ({
    stats: await getDashboardStats(),
  }))
  .page(({ data: { stats } }) => <Dashboard stats={stats} />)
```

## Layout Loader

A `_route.tsx` layout can load data for itself and its descendants. `layout` is type-only metadata; filesystem nesting determines the runtime layout tree.

```tsx
// src/pages/dashboard/_route.tsx
import { defineRoute } from "@teyik0/furin"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssr" })
  .loader(async ({ request }) => ({
    user: await getSession(request),
  }))
  .layout(({ children, data: { user } }) => (
    <div>
      <DashboardNav user={user} />
      {children}
    </div>
  ))
```

A child loader receives every parent field as an individually awaitable promise. This keeps independent loaders parallel.

```tsx
// src/pages/dashboard/index.tsx
import { defineRoute } from "@teyik0/furin"
import { route as parentRoute } from "./_route"

export const route = defineRoute()
  .config({ layout: parentRoute, mode: "ssr" })
  .loader(async ({ user }) => {
    const { id } = await user
    return { stats: await getDashboardStats(id) }
  })
  .page(({ data: { stats, user } }) => <Dashboard stats={stats} user={user} />)
```

Use `Promise.all` when a loader needs several parent fields. A single `await` is enough for a deferred parent field because JavaScript promises flatten nested promises.

## Loader Context

Loaders receive the Elysia context plus Furin's typed route values:

| Property | Type | Description |
| --- | --- | --- |
| `request` | `Request` | incoming request |
| `params` | inferred from `config({ params })` | validated path params |
| `query` | inferred from `config({ query })` | validated query values |
| `set`, `headers`, `cookie`, `redirect` | Elysia helpers | request and response controls |
| parent loader fields | `Promise<T>` | individually awaitable ancestor data |

## Typed Query

`config()` accepts a query schema without requiring a params schema.

```tsx
import { defineRoute } from "@teyik0/furin"
import { t } from "elysia"
import { route as parentRoute } from "../root"

export const route = defineRoute()
  .config({
    layout: parentRoute,
    mode: "ssr",
    query: t.Object({
      page: t.Optional(t.Number({ default: 1 })),
      tag: t.Optional(t.String()),
    }),
  })
  .loader(async ({ query }) => ({
    posts: await db.getPosts(query),
  }))
  .page(({ data: { posts }, query }) => <PostList page={query.page} posts={posts} />)
```

Query schemas from nested layouts and the page are merged in the generated `RouteMap`. Fields with a non-null default are required after Elysia validation; optional fields without a default remain optional.

## Typed Params

Every dynamic segment must be covered by the local params schema. Generation fails before writing artifacts when the path and schema drift.

```tsx
import { defineRoute } from "@teyik0/furin"
import { t } from "elysia"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssr", params: t.Object({ slug: t.String() }) })
  .loader(({ params }) => getPost(params.slug).then((post) => ({ post })))
  .page(({ data: { post } }) => <article>{post.title}</article>)
```

## Request-Specific Data

For SSG, ISR, or PPR data that must never enter the public loader payload, put `requestLoader()` before `loader()`. Its result is exposed separately as `requestData`.

```tsx
import { Suspense, use } from "react"
import { defineRoute } from "@teyik0/furin"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssg" })
  .requestLoader(async ({ cookies }) => ({
    session: await readSession(cookies),
  }))
  .loader(() => ({ title: "Dashboard" }))
  .page(({ data: { title }, requestData }) => (
    <Suspense fallback={<DashboardSkeleton />}>
      <Dashboard session={use(requestData).session} title={title} />
    </Suspense>
  ))
```

## Deferred Data

Use `defer()` inside `loader()` for public fields that should stream after the initial shell. See [Deferred Data Streaming](/docs/defer).
