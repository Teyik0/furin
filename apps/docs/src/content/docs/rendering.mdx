# Rendering Modes

Rendering metadata belongs in `config()`. The same chain then declares loaders, head metadata, and its `page()` or `layout()` terminal.

## SSR

SSR is the default mode.

```tsx
import { defineRoute } from "@teyik0/furin"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssr" })
  .loader(async ({ request }) => ({
    user: await getSession(request),
  }))
  .page(({ data: { user } }) => <Dashboard user={user} />)
```

Use SSR for personalized pages and request-time data. SSR supports [deferred streaming](/docs/defer).

## SSG

```tsx
import { defineRoute } from "@teyik0/furin"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssg" })
  .page(() => <div>This page is pre-rendered</div>)
```

Dynamic SSG params are also declared in `config()`.

```tsx
import { defineRoute } from "@teyik0/furin"
import { t } from "elysia"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({
    layout: rootRoute,
    mode: "ssg",
    params: t.Object({ slug: t.String() }),
    staticParams: async () => {
      const slugs = await db.getAllSlugs()
      return slugs.map((slug) => ({ slug }))
    },
  })
  .loader(async ({ params }) => ({
    post: await db.getPost(params.slug),
  }))
  .page(({ data: { post } }) => <Post post={post} />)
```

## ISR

Pair `mode: "isr"` with `revalidate`.

```tsx
import { defineRoute } from "@teyik0/furin"
import { t } from "elysia"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({
    layout: rootRoute,
    mode: "isr",
    params: t.Object({ id: t.String() }),
    revalidate: 60,
  })
  .loader(async ({ params }) => ({
    product: await db.getProduct(params.id),
  }))
  .page(({ data: { product } }) => <ProductPage product={product} />)
```

## Personalized Cached Routes

Keep cacheable data in `loader()` and request-specific data in `requestLoader()`.

```tsx
import { defineRoute } from "@teyik0/furin"
import { Suspense, use } from "react"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "isr", revalidate: 60 })
  .requestLoader(({ cookies }) => ({
    user: getUser(cookies.get("session")),
  }))
  .loader(async () => ({
    catalog: await getPublicCatalog(),
  }))
  .page(({ data: { catalog }, requestData }) => (
    <>
      <Catalog value={catalog} />
      <Suspense fallback={<AccountSkeleton />}>
        <Account value={use(requestData).user} />
      </Suspense>
    </>
  ))
```

The component receives `requestData` as a promise. Only public loader data enters the cached shell. Static export rejects `requestLoader()` because no request runtime exists.

## Composite React Server Components

RSC is a loader value, not a rendering mode. Use the explicit composite API.

```tsx
import { defineRoute } from "@teyik0/furin"
import { CompositeComponent, createCompositeComponent } from "@teyik0/furin/rsc"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssr" })
  .loader(async () => ({
    card: await createCompositeComponent<{
      Action: React.ComponentType<{ productId: string }>
    }>(({ Action }) => (
      <article>
        <Action productId="product-1" />
      </article>
    )),
  }))
  .page(({ data: { card } }) => (
    <CompositeComponent
      Action={({ productId }) => <button>Add {productId}</button>}
      src={card}
    />
  ))
```

The server fragment is encoded as Flight. Client interactivity enters through children, component slots, or render props. Furin does not expose React Server Functions; mutations remain Elysia/Eden Treaty endpoints.

## Head Metadata

`head()` follows `loader()` and precedes the terminal.

```tsx
import { t } from "elysia"
import { defineRoute } from "@teyik0/furin"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssr", params: t.Object({ slug: t.String() }) })
  .loader(async ({ params }) => ({ post: await db.getPost(params.slug) }))
  .head(({ data: { post } }) => ({
    meta: [
      { title: post.title },
      { content: post.excerpt, name: "description" },
    ],
  }))
  .page(({ data: { post } }) => <Post post={post} />)
```

| Mode | Configuration | Best for |
| --- | --- | --- |
| `ssr` | `config({ layout, mode: "ssr" })` | request-time and personalized data |
| `ssg` | `config({ layout, mode: "ssg" })` | content that changes rarely |
| `isr` | `config({ layout, mode: "isr", revalidate })` | cached pages refreshed periodically |
