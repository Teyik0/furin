# Head & SEO

`head()` derives document metadata from validated params, search state, and public loader data. Furin renders it during SSR, SSG, and ISR, then replaces the route-owned head descriptors during SPA navigation.

```tsx
import { defineRoute } from "@teyik0/furin";
import { t } from "elysia";
import { route as rootRoute } from "../root";

export const route = defineRoute()
  .config({
    layout: rootRoute,
    mode: "ssr",
    params: t.Object({ slug: t.String() }),
  })
  .loader(async ({ params }) => ({ post: await getPost(params.slug) }))
  .head(({ data, params }) => ({
    meta: [
      { title: data.post.title },
      { name: "description", content: data.post.excerpt },
      { property: "og:title", content: data.post.title },
      { property: "og:type", content: "article" },
    ],
    links: [
      { rel: "canonical", href: `https://example.com/blog/${params.slug}` },
    ],
  }))
  .page(({ data }) => <Article post={data.post} />);
```

Metadata for cached routes should remain public and deterministic. Although head props include `requestData`, prefer values that remain valid across cache hits and put request-private values in the rendered body.

## Descriptor Reference

### Metadata

```ts
head: () => ({
  meta: [
    { title: "Page title" },
    { charSet: "utf-8" },
    { name: "description", content: "Page summary" },
    { property: "og:image", content: "https://example.com/cover.png" },
    { httpEquiv: "refresh", content: "30" },
    { tagName: "meta", "data-custom": "value" },
  ],
});
```

`<HeadContent />` already emits UTF-8 charset and viewport descriptors. Add them manually only when you intentionally need another value.

### Links

```ts
head: () => ({
  links: [
    { rel: "canonical", href: "https://example.com/docs" },
    { rel: "preload", href: "/public/hero.webp", as: "image" },
  ],
});
```

Application CSS should normally be imported from route or component code so Bun can include it in the asset graph. Use `links` for external stylesheets or resource hints.

### JSON-LD

```ts
head: ({ data }) => ({
  meta: [
    {
      "script:ld+json": {
        "@context": "https://schema.org",
        "@type": "Article",
        headline: data.post.title,
      },
    },
  ],
});
```

Furin serializes the object as escaped JSON inside `application/ld+json`.

### Inline Scripts And Styles

```ts
head: () => ({
  scripts: [{ type: "module", children: `console.log("loaded")` }],
  styles: [{ children: ".announcement { color: tomato; }" }],
});
```

`children` is raw HTML. Never interpolate user-controlled or unsanitized loader data. Route head scripts are document metadata, not a reliable SPA analytics lifecycle; track navigations from client code instead.

## Root Requirement

The root layout must expose the head insertion point:

```tsx
import { defineRootRoute, HeadContent, Scripts } from "@teyik0/furin";

export const route = defineRootRoute()
  .config({ mode: "ssg" })
  .layout(({ children }) => (
    <html lang="en">
      <head>
        <HeadContent />
      </head>
      <body>
        {children}
        <Scripts />
      </body>
    </html>
  ));
```

Keep one title and one canonical URL in a page's final descriptor set. Furin preserves declaration order and does not deduplicate competing metadata for you.
