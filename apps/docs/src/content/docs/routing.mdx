# File-Based Routing

Furin scans `src/pages` and turns files into routes. Pages live in `.tsx` files, while `_route.tsx` files define layouts and route-level config for a directory.

## Basic Pages

```text
src/pages/index.tsx       -> /
src/pages/about.tsx       -> /about
src/pages/blog/index.tsx  -> /blog
```

## Dynamic Segments

Use square brackets for params:

```text
src/pages/blog/[slug].tsx   -> /blog/:slug
src/pages/docs/[...path].tsx -> /docs/*
```

Declare typed params in `config()` on the page route:

```tsx
// src/pages/blog/[slug].tsx
import { t } from "elysia"
import { defineRoute } from "@teyik0/furin"
import { route as parentRoute } from "./_route"

export const route = defineRoute()
  .config({
    layout: parentRoute,
    mode: "ssr",
    params: t.Object({ slug: t.String() }),
  })
  .loader(async ({ params }) => {
    const post = await db.getPost(params.slug)
    return { post }
  })
  .page(({ data: { post } }) => <article>{post.title}</article>)
```

```tsx
// src/pages/blog/_route.tsx
import { defineRoute } from "@teyik0/furin"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssr" })
  .layout(({ children }) => children)
```

## Layout Files

Files named `_route.tsx` define route-level config and layouts for their directory:

```text
src/pages/blog/_route.tsx
src/pages/blog/index.tsx
src/pages/blog/[slug].tsx
```

```tsx
// src/pages/blog/_route.tsx
import { defineRoute } from "@teyik0/furin"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({ layout: rootRoute, mode: "ssr" })
  .layout(({ children }) => (
    <div className="mx-auto flex max-w-5xl gap-8 px-4 py-10">
      <aside>Sidebar</aside>
      <main>{children}</main>
    </div>
  ))
```

## Catch-All Routes

Catch-all segments are written with `[...name]`. Furin turns them into `*` in the generated runtime pattern.

```text
src/pages/docs/[...path].tsx -> /docs/*
```

If you declare a schema for that route, the runtime param key is `"*"`:

```tsx
import { t } from "elysia"
import { defineRoute } from "@teyik0/furin"
import { route as rootRoute } from "../root"

export const route = defineRoute()
  .config({
    layout: rootRoute,
    mode: "ssr",
    params: t.Object({ "*": t.String() }),
  })
  .page(({ params }) => <DocsPage path={params["*"]} />)
```

## Typed Navigation

Furin generates `furin-env.d.ts` so `<Link />` and `useSearch` are fully typed from the route manifest.

```tsx
import { Link } from "@teyik0/furin/link"

<Link to="/docs/rendering">Rendering</Link>
```

When a route declares a `query` schema, `search` is typed from that schema.

```tsx
<Link to="/search" search={{ page: 2 }} />
```

The same types drive `useSearch` from `@teyik0/furin/search`:

```tsx
import { useSearch } from "@teyik0/furin/search";

const [search, setSearch] = useSearch("/products");
```

Query defaults declared in the schema are available in `search`, but Furin omits them from generated URLs. `setSearch({ page: 1 })` navigates to `/products` when `page` defaults to `1`; `setSearch({ page: 2 })` navigates to `/products?page=2`.

Make sure `furin-env.d.ts` is included in your app `tsconfig.json`:

```json
{
  "include": ["src/**/*", "furin-env.d.ts"]
}
```
