# Windows and lifecycle

The controller is available as `desktop` in Elysia handlers with `desktopContext`, or through `getDesktopHost()` in a native module. Both refer to the same managed host.

## The primary window

`desktop.window` is a readonly getter for the current Electrobun `BrowserWindow`, with all its native methods and the original `webview` types. It becomes `undefined` after that window closes.

`desktop.open()` shows and focuses the primary window, or creates it again after it closes, and returns the SDK instance. It throws before native readiness, so do not call it at native module top level or await it during application startup.

## Additional windows

Create named windows from a ready desktop context (for example inside a route handler that uses `desktopContext`):

```ts
const settings = desktop.windows.create("settings", {
  path: "/settings",
  title: "Settings",
  frame: { width: 640, height: 480 },
});

desktop.windows.get("settings");
```

`path` is a route in your Furin app. Each managed window receives its own one-use authenticated bootstrap URL. Furin owns the window's URL, HTML, views root and navigation rules; other SDK window options pass through. The name `"main"` is reserved for the primary window.

`get(name)` returns `BrowserWindow | undefined` with the SDK's default RPC type, because a runtime name carries no RPC declaration. Keep the return value of `create(name, { rpc, ... })` when exact RPC inference matters.

## Background mode

A `background` callback controls whether the application can stay alive after its last managed window closes:

```ts
import { desktopApp } from "@teyik0/furin-electrobun/server";
import { Elysia } from "elysia";

new Elysia()
  .use(desktopApp({
    window: { title: "Relay" },
    background: () => true,
  }));
```

Background mode does not create a tray or menu; add those with the [native SDK](/docs/desktop/native-apis).

## Shutdown and restart

Use `desktop.quit()` and `desktop.restart()` for coordinated shutdown: the host closes managed windows and runs backend cleanup once. Release application resources in Elysia `.onStop()`.

Raw SDK windows and views are outside Furin's managed ownership and authentication. Use managed windows for routes that need the application session.
