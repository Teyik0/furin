# Build and distribute a desktop app

The desktop build packages your Furin application and generates the Electrobun host around it. Packaging stays in `furin.config.ts`; runtime window policy stays on the Elysia root.

## Build the application

After [initialization](/docs/desktop/installation):

```sh
bun run build:desktop
```

`build:desktop` runs `furin-electrobun build`. It builds the inert Furin application artifact (`furin build --target bun --output app`), generates the native bootstrap, prepares the pinned SDK and regenerates its type aliases, then packages the app into `.furin/electrobun/build`. Builds use the `stable` channel; run `furin-electrobun build --env=dev` for a development-channel build.

The packaged app opens the listener configured by `.listen()`, so stop any Web server using the same port before launching it.

## Choose a renderer

Native system WebViews are the default. CEF and WGPU assets are not bundled unless explicitly enabled for the target platform.

```ts
// furin.config.ts
import { defineConfig } from "@teyik0/furin/config";
import { defineDesktopConfig } from "@teyik0/furin-electrobun";

export default defineConfig({
  desktop: defineDesktopConfig({
    app: { name: "Relay", identifier: "local.furin.relay" },
    build: { mainProcess: "bun", mac: { bundleCEF: true } },
  }),
});
```

Enable `bundleCEF: true` (or `bundleWGPU: true`) in `build.mac`, `build.win` or `build.linux` for each platform that needs it. A managed window using `renderer: "cef"` requires CEF on the current platform, and `defineDesktopConfig` rejects a platform `defaultRenderer: "cef"` without `bundleCEF: true`.

## Runtime dependencies and files

`desktop.external` lists packages that cannot be bundled. They are kept external in the Furin artifact and copied with their dependencies so it stays relocatable. It accepts package names, not filesystem paths.

Other Electrobun settings (platform permissions, views, copy rules, bundler options, scripts and release configuration) pass through `defineDesktopConfig`. Furin reserves the generated main entry, its helper and copy destinations, and `runtime.exitOnLastWindowClosed`.

## Release workflow

Set a stable application identifier and version, build on the appropriate target environment, and test the packaged artifact's startup, data directory and shutdown. Then configure [signing](/docs/desktop/signing) and [updates](/docs/desktop/updates) using the original SDK's release mechanisms.

See the [Relay example](https://github.com/teyik0/furin/tree/main/examples/electrobun-todo) for working scripts and configuration.
