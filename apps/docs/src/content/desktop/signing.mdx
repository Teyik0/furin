# Sign your desktop app

Signing and notarization use Electrobun's platform build settings, which `defineDesktopConfig` passes through from `desktop` in `furin.config.ts`.

## Configure the macOS build

```ts
// furin.config.ts
import { defineConfig } from "@teyik0/furin/config";
import { defineDesktopConfig } from "@teyik0/furin-electrobun";

export default defineConfig({
  desktop: defineDesktopConfig({
    app: { name: "Relay", identifier: "local.furin.relay" },
    build: {
      mainProcess: "bun",
      mac: { codesign: true, notarize: true, createDmg: true },
    },
  }),
});
```

Prepare the signing identity, credentials and target build environment using [Electrobun's code-signing guide](https://docs.electrobun.dev/electrobun/guides/code-signing/). Keep credentials in your build environment or CI secret store.

## Verify the release artifact

Development builds do not exercise the release-signing pipeline. Test a signed release end to end: installation, launch and access to the application's persistent data.

Platform requirements and signing support come from the pinned Electrobun SDK; Furin adds no signing service of its own.
